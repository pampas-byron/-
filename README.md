# 日序 · 日程与任务

一个安静的日程与任务管理单页应用。纯前端实现，无需安装依赖，数据只保存在当前浏览器的本地存储中。

## 快速开始

直接双击打开 `index.html` 即可使用。

如果浏览器对 `file://` 地址的本地存储有限制，也可以在当前目录启动一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://127.0.0.1:8080>。

首次打开是空状态，可以点击「载入示例任务」快速体验完整界面。

## 手机独立使用（PWA）

公网地址：<https://rishi-mobile-449a6b-xeeu43j71e.brewpage.app/>

这个版本已经配置成可安装的 PWA，不需要电脑保持开机：

- **iPhone / iPad**：用 Safari 打开上面的链接 → 分享按钮 → 添加到主屏幕 → 添加。
- **Android**：用 Chrome 或 Edge 打开 → 浏览器菜单 → 安装应用 / 添加到主屏幕。
- 安装后应用页面会缓存到手机，断网也能打开；首次安装需要联网。

当前公网地址使用临时免费托管，保留到 **2026 年 11 月 24 日**，页面右侧会显示托管服务的小角标。若需要永久可访问的地址，建议之后绑定一个免费的 Netlify、Vercel 或 GitHub Pages 账号重新部署。

> 手机和电脑的任务数据互相独立，均保存在各自浏览器的本地存储中，不会自动同步。

## 部署到 GitHub Pages（永久链接）

如果希望长期使用一个稳定、免费的网址，可以把应用发布到 GitHub Pages。

1. 登录 GitHub，打开 <https://github.com/new>，新建一个 **Public** 仓库，例如 `rishi`。
2. 创建后点击 **Add file → Upload files**。
3. 上传 `index.html`、`manifest.json`、`sw.js` 以及整个 `icons` 文件夹。注意：要上传这些文件本身，让 `index.html` 位于仓库根目录，而不是把整个 `rishi-app` 文件夹传上去。
4. 点击 **Commit changes**。
5. 打开仓库的 **Settings → Pages**，把 **Source** 设为 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，点击 **Save**。
6. 等待 1–3 分钟，访问 `https://<你的GitHub用户名>.github.io/rishi/`。
7. 在手机浏览器打开该地址，再选择「安装应用 / 添加到主屏幕」。

GitHub Pages 提供免费的 HTTPS，因此 PWA 和离线缓存可以正常工作。新的 GitHub Pages 地址和临时公网地址属于不同网站，两者的任务数据不会自动同步。

## 功能

- **任务管理**：新增、编辑、删除；支持标题、备注、截止日期时间、优先级（高 / 中 / 低）和分类标签。
- **两种视图**：列表视图按截止时间分组；日程视图用日期时间轴展示安排，可切换今天、本周、未来，也可以点击月历中的日期查看当天。
- **提醒**：可选提前 10 分钟、30 分钟、1 小时、3 小时、1 天，或自定义分钟数。到期前通过页面内通知提醒，提醒状态会持久化，刷新页面不会重复提醒。
- **逾期提示**：超过截止时间的未完成任务会以红色高亮，并显示逾期时长。
- **完成状态**：勾选完成后自动加删除线、置灰并归入「已完成」分组；支持撤销完成、一键清理已完成任务（附带撤销）。
- **筛选与排序**：按优先级、分类、完成状态筛选，支持关键词搜索；可按截止时间、优先级或创建时间排序。
- **统计概览**：今日待办、已逾期、本周完成、未来 7 天及完成率。
- **主题与响应式**：浅色 / 深色主题切换，自动适配桌面、平板和手机。
- **可安装 PWA**：支持添加到手机主屏幕，并缓存页面供离线使用。
- **本地优先**：所有任务、主题、视图偏好都保存在 `localStorage`，不会上传任何数据。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `N` | 新建任务 |
| `/` 或 `Ctrl` / `Cmd` + `K` | 聚焦搜索框 |
| `Esc` | 关闭弹窗 / 清除日历日期筛选 |
| `Enter` / `Space` | 在聚焦的任务卡片上打开编辑 |

## 提醒说明

提醒检测每 15 秒运行一次，依赖页面处于打开状态。浏览器在后台标签页可能会节流计时器，因此提醒可能会有少量延迟。建议把页面保持在前台，或在一个独立标签页中长期打开。

## 数据与隐私

- 任务数据：`localStorage` 键名 `rishi.tasks.v1`
- 主题：`rishi.theme`
- 视图：`rishi.view`
- 最近使用的分类：`rishi.lastCategory`

清除浏览器站点数据会同时清除任务。应用没有后端，也不会上传任何内容。
